# Notion出力の修正依頼(2026-09-20)

実データで確認した結果、3点の対応をお願いします。

## 1. 証拠カテゴリ(5.1〜5.7)を独立したページにする

現状はNotionの目次ブロックによる同一ページ内アンカーリンクになっており、
クリックしてもRunページ内で該当見出しにジャンプするだけです。これを
Runページの**子ページ(独立したNotionページ)**として作り直してください。
Runページ側は各子ページへのリンク一覧に簡略化し、本文は子ページ側に
移してください。

## 2. 候補ページに「この候補が上位にある理由」の説明文が見当たらない

PR #26の設計では候補データベースの各ページ本文に入っているはずですが、
実際に確認したところ見つかりませんでした。実装漏れの可能性があるので
調査し、確実に入るようにしてください。

## 3. (追加要望)候補ページに、そのタンパク質が持つドメイン情報も入れてほしい

候補ごとのページを開いたときに、順位理由の説明文に加えて、そのタンパク質が
持つドメイン構成(検出されたドメイン・ドメインファミリー。既存のスコアリング
パイプラインがfunctional/domain evidenceの算出に使っているデータ、Excelの
`04_Score_Breakdown`/`11_Raw_Audit`にある情報)を、人間が読める形で小節として
追加してください。Word側の「候補詳細」節に同等の情報が無ければ、共有
ナラティブ層(`report_sections.py`)に追加して、WordとNotionの両方に
反映されるようにしてください。

## 変更しなくてよい点

順位表(7章)はRunページに残して構いません。全体を見渡す一覧として有用
です。個々の候補の詳細説明はRunページ側には重複して書かず、候補データ
ベースの各ページ側を正としてください。

## 報告フォーマット

対応が終わったら、他のPRと同じ形式(設計との差分・テスト結果・実データ
での確認結果)で報告してください。
